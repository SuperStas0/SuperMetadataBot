# Super Metadata
Telegram bot that will allow to download audio from youtube and edit its metadata

# Quick Start
## Requirements
- Telegram account
- Node js
- 4.20$

## Building
1. Download/Clone repository: `git clone https://github.com/SuperStas0/SuperMetadata.git` or `git clone git@github.com:SuperStas0/SuperMetadata.git`
2. Build dependencies

## Launching
1. Create a new bot in telegram using [@BotFather](https://t.me/BotFather) and copy it's api key
2. Run `start.js` and enter bot's api key and needed fields **for your account**
2.1. When asked to enter 2FA code you gonna receive code from Telegram
3. Run `main.js` to start the bot
3.1. Message `/start` to bot to start using it

# Usage
To load audio into bot use any:
- Use built in youtube search
- Send youtube video link
- Send existing audio in telegram
Then you will be able to:
- Trim
- Change title
- Change performer
- Change poster
- Change duration
